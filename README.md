# Отчёт по авансам и оплате работ

CLI строит два CSV-отчёта на заданную дату: по работам и по договорам. Используются только стандартная библиотека Python и точная арифметика `Decimal`.

## Запуск

```bash
python3 report.py --data data --as-of 2026-11-10 --out report
```

Будут созданы `report/work_report.csv` и `report/contract_report.csv`. В таблицах суммы записаны с точностью до копейки и точкой как десятичным разделителем. Статус `planned` в отчёте означает, что работа ещё не была принята или отменена на выбранную дату.

## Показательный отчёт

Папка `report/` содержит результат для даты проверки 10.11.2026.

В отчёте по договору указаны сумма договора, активная стоимость работ, стоимость отменённых работ, фактически выплачено, остаток к оплате, очередь платежей и сумма фактических выплат, распределённая по работам. Платёж в очереди не считается уже выплаченным и остаётся частью остатка к оплате.

## Что включено

- `report.py` — программа.
- `data/` — исходные файлы задания без изменений.
- `report/` — отчёт на дату проверки.
- `DECISIONS.md` — допущения и их влияние.
- `NOTE_TO_ACCOUNTANT.md` — короткая записка бухгалтеру.
